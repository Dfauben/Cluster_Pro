## Como usar este modulo

Este bloque no introduce conceptos nuevos. Cada escenario te pide mezclar piezas que ya viste en los modulos anteriores. La idea es resolverlo sin ayuda paso a paso y con un nivel de detalle suficiente para demostrar que entiendes lo que estas mirando.
