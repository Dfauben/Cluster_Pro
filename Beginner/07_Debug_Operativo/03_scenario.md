# Beginner 07 - Lab

## Contexto

Una app no termina de arrancar y tienes que mirar el problema sin ir a ciegas.

## Tarea

- sacar la primera pista con logs
- revisar el estado del pod con describe
- usar events si sigue faltando contexto
- decidir si un reinicio tiene sentido

## Criterio de salida

Si puedes seguir el orden correcto, encontrar la causa util y decidir con criterio si reiniciar ayuda, el lab esta resuelto.
