## Criterio de salida

Cuando termines `setup/`, debes tener:

- WSL2 instalado y funcionando
- Ubuntu disponible como distro por defecto o principal
- Docker Desktop con backend WSL 2 activo
- `kubectl`, `kind` y `helm` accesibles desde WSL
- el entorno listo para crear el primer cluster del laboratorio

## Regla de uso

Windows se usa para instalar y configurar.
El trabajo diario del lab se hace en WSL.
